## Como agregar un trabajo nuevo

1. Entra a la carpeta de la semana correspondiente, por ejemplo `semana-13`.
2. Copia ahi tus archivos (documentos, codigo, imagenes, etc).
3. Guarda los cambios en Git y sube a GitHub (ver seccion "Conectar con GitHub" en el README principal).
